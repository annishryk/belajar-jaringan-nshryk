# Belajar Jaringan with Cisco

Website pembelajaran dasar jaringan komputer yang dilengkapi dengan **Kalkulator IPv4 / CIDR** interaktif berbasis *client-side*.

## Fitur Utama
- Materi dasar mengenai Network Fundamentals, Switching, dan Routing.
- Kalkulator IPv4 / CIDR otomatis (menghitung Network Address, Broadcast, Subnet Mask, Wildcard, Host Range, dan Total/Usable Hosts).
- Breakdown biner untuk IP, Subnet Mask, dan Network Address.
- Fitur Riwayat Perhitungan (History) menggunakan `localStorage` dengan opsi hapus riwayat.
- Fitur tombol *Copy* instan pada breakdown biner.
- Mendukung *Dark Mode* & *Light Mode*.

## Teknologi yang Digunakan
- **HTML5**
- **Tailwind CSS**
- **JavaScript (Vanilla)**
